# 🌩️ StormSense AI
### AI-Powered Convective-Scale Nowcasting & Early Warning System (0–6h)

> **Built for the Smart India Hackathon (SIH) — Severe Convective Storms & Hailstorm Prediction**

---

## 🧭 Core Philosophy & Architectural Boundary
- **Deterministic & ML Numerical Core**: Predictions are **NOT** generated by hallucinating LLMs. Physical nowcasting, trajectory advection, and hazard probabilities are computed locally by a **Scikit-Learn Multi-Output Random Forest Regressor** trained on atmospheric + radar + satellite + lightning features.
- **AI Decision Support Layer (Grok 4.7)**: xAI's Grok 4.7 is utilized exclusively as an **explainability and tactical emergency decision-support layer** ("Why HIGH RISK?", executive threat briefings, and civil defense recommendations).

## 🚀 Quickstart: Running the Prototype

### 1. Start the FastAPI Backend
```bash
cd backend
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```
- **Backend API**: `http://localhost:8000`
- **Interactive Swagger Docs**: `http://localhost:8000/docs`
- **Live WebSocket Endpoint**: `ws://localhost:8000/ws/live`

*(Optional)* To use live Grok 4.7 instead of the built-in reasoning engine, edit `backend/.env`:
```env
XAI_API_KEY=your_xai_grok_key_here
```

### 2. Start the React Frontend
```bash
cd frontend
npm run dev
```
- Open **`http://localhost:5173`** in your browser.

## 🎯 Key Hackathon Demonstration Highlights

1. **Live Convective Lifecycle**:
   - Switch scenarios via the top dropdown: *Developing Storm*, *Rapid Intensification*, *Severe Convective Storm*, or *Storm Dissipation*.
   - Watch the storm marker, trajectory line, and multi-tier hazard buffers update live on the MapLibre GIS map.

2. **Real-World Atmospheric Context**:
   - Integrates live meteorological variables from **Open-Meteo** (no API key needed) for CAPE, Convective Inhibition, and surface moisture.

3. **0–6 Hour Scrubbable Timeline**:
   - Click along waypoints (`NOW`, `+15m`, `+30m`, `+45m`, `+1h`, `+2h`, `+3h`, `+6h`) to inspect projected future storm risk and the Recharts trend forecast.

4. **"What-If?" Scenario Simulator**:
   - Adjust Storm Core Intensity, Relative Humidity, and Inflow Wind sliders to observe how the Random Forest model recalculates hazard probabilities in real-time.

5. **AI Convective Explainability Dossier**:
   - Click **"Why Risk?"** or **"Threat Briefing"** to view structured feature contributions (CAPE, Doppler Reflectivity dBZ, Updraft velocity, Lightning Jump, and Convective Inhibition).
